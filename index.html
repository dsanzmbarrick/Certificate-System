Cómo generar un certificado
Para visualizar la información y generar certificados, favor seguir las instrucciones enumeradas. Primero busque el empleado por ID o nombre; luego valide los resultados y genere el certificado correspondiente.
1. BuscarEscriba el ID o parte del nombre del empleado.
2. RevisarVerifique que los resultados correspondan a la persona correcta.
3. GenerarHaga clic en PDF o seleccione competencias y use Generar seleccionados.
4. DescargarComplete el nivel actual y el nivel destino, si aplica, y descargue el certificado.
